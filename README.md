# 86 -EIGHTY-SIX- Game Project

> 기획 단계 저장소 — 모든 설정은 임시이며 추후 변경할 수 있습니다.

## 프로젝트 목적
*86 -EIGHTY-SIX-* 세계관을 바탕으로 스토리 캠페인, 오픈월드, 멀티플레이를 결합한 Roblox 게임을 기획합니다.

## 현재 상태
- 단계: 사전 기획
- 제작/모델링/코딩: 아직 시작하지 않음
- 공식 설계 기준: 이 GitHub 저장소
- 기획 문서 상태: 임시 초안

## 설정 상태 표기
- **CONFIRMED**: 현재 대화에서 사용자가 선택하거나 명시한 임시 결정
- **PROPOSED**: 검토를 위해 제안한 안
- **PENDING**: 아직 정하지 않은 항목

CONFIRMED도 최종 고정이 아닙니다. 사용자가 원하면 언제든 수정합니다.

## 핵심 원칙
- 기획을 충분히 마무리한 후 제작에 들어갑니다.
- 원작의 세계관과 주요 흐름을 존중합니다.
- 원작 대사, 장면, 음악, 모델 등의 저작권 보호 대상 콘텐츠를 무단 복제하지 않습니다.
- Roblox 플랫폼 정책과 권리 관계를 검토한 뒤 공개 범위를 결정합니다.
