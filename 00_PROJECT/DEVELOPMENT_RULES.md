# Development Rules

## 기획 단계
- 먼저 기획을 충분히 완성하고, 이후 제작에 착수합니다.
- 사용자 승인 없이 모델링, 코딩, Roblox Studio 구현을 시작하지 않습니다.
- 모든 설정은 임시이며 사용자 요청으로 변경할 수 있습니다.
- 확정/제안/미정 상태를 구분합니다.
- 제안한 내용을 사용자가 승인한 결정처럼 기록하지 않습니다.

## 문서/협업
- GitHub 저장소를 공식 설계 기준(SSOT)으로 사용합니다.
- 변경 사항은 문서에 반영하고 결정 기록을 갱신합니다.
- main에는 검토된 안정 문서/버전을 둡니다.
- 구현 단계에서는 기능별 브랜치와 작은 커밋을 권장합니다.
- Codex는 작업 전 저장소의 최신 문서를 확인하고, 문서와 충돌하는 구현을 임의로 진행하지 않습니다.

## 저작권 및 플랫폼
- 원작의 대사/소설/각본/음악/이미지/모델을 무단 복제하거나 대량 재현하지 않습니다.
- 독자 제작 또는 적법하게 사용 허가된 자산을 우선합니다.
- 공개 전 관련 권리와 Roblox 정책을 검토합니다.
