# Technical Design

상태: 알파 공통 기반의 초기 기술 설계 대상

기술 아키텍처 전체를 기획 마지막까지 미루지 않습니다. 알파 핵심 시스템과 병행해 서버/클라이언트 책임, 데이터 경계, 네트워크 권한 등 선행 구조를 먼저 설계하고, 상세 구현과 수치는 프로파일링 및 테스트 과정에서 확정합니다.

## 우선 설계
- Roblox Experience 및 Place 이동 구조
- 서버/클라이언트 책임 분리와 서버 권한 검증
- 계정 공통 데이터와 서버별 월드 데이터 분리
- 저장·복구·재접속 및 서버 종료 처리
- 전투 판정, 투사체, 부위 피해의 네트워크 동기화
- 레기온 AI 관리자와 거리별 활성화 단계
- 스트리밍, 메모리, 물리·AI 연산 최적화
- 오류 기록, 테스트 환경, 배포·롤백 절차

## 후속 상세화
- 별도 PvE 인스턴스 및 매칭
- PvP 매치 서버와 공정성/치트 방지
- 스토리 캠페인 전용 세션 및 저장
- Blender 에셋 파이프라인과 대규모 자산 관리

실제 기술 선택과 구현은 기획 승인 이후 진행합니다.
