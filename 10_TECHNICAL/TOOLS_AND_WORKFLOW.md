# Tools & Workflow

상태: 임시 협업 계획

## 도구
- Blender: 3D 모델링 및 애니메이션
- Roblox Studio: 월드, UI, 물리, 멀티플레이, 통합, 테스트, 배포
- GPT Codex: 구현 단계의 Luau 작성, Blender Python 자동화, 프로젝트 파일 작업, 코드 검토 및 자동화
- Claude: 필요 시 보조 코드 검토, 설계 검증, 대안 및 문제 해결
- ChatGPT 기획 프로젝트: 세계관/스토리/시스템 기획, 문서화, 검토
- GitHub: 공식 문서 및 버전 이력의 기준

## 협업 원칙
- ChatGPT 기획 프로젝트와 Codex 프로젝트는 별도 컨텍스트입니다. 자동으로 대화 내용이 공유된다고 가정하지 않습니다.
- Codex는 작업 전 GitHub의 최신 문서를 확인합니다.
- 설계 변경은 먼저 문서에 반영한 뒤 구현에 적용합니다.
- 로컬 컴퓨터는 백업/로컬 작업 공간으로 사용하고, GitHub를 기준 저장소로 둡니다.

## Git 사용 권장
- main: 검토된 안정 문서/버전
- 기능 브랜치: 기능별 작업
- 작은 단위의 커밋과 명확한 커밋 메시지
- 큰 바이너리 에셋은 Git LFS 검토
- 비밀키, 비밀번호, 개인 토큰은 절대 커밋하지 않음

## 구현 시작 전
기획 완료 및 사용자의 명시적 승인 전에는 구현 작업을 시작하지 않습니다.
