## 검토 시 주의

- `KEEP`: 기존 결정을 유지하자는 의견이며, 그 자체로 승인 변경을 뜻하지 않는다.
- `CHANGE`, `REMOVE`, `NEW`: 기존 결정과 충돌하거나 새 규칙을 제안할 수 있으므로 사용자 검토가 필요하다.
- `DEFER`: 알파 이후로 미루자는 제안이며, 기존 장기 기획을 삭제하지 않는다.
- 수치·성능 목표·플레이 시간·서버 인원 등은 실측 전 가설로 취급한다.
- 기술 관련 【사실】 표기도 실제 구현 전 최신 Roblox 공식 문서와 Studio 테스트로 재검증한다.
- 문서 본문에서 `09_DECISION_CHANGE_REGISTER.md`, `10_VALIDATION_CHECKLIST.md`를 참조하는 곳이 있으나, 이번에 전달된 업로드에는 해당 두 파일이 포함되지 않아 이 저장소에도 추가하지 않았다. 해당 파일을 받으면 별도 문서로 추가한다.
