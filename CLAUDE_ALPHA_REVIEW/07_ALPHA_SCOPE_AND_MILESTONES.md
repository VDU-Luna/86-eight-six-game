# 07. 알파 개발 범위 및 마일스톤

- 작성일: 2026-11-20 · 버전 v0.1 · 기준 `main` / `9d2d42b`
- 상태: 모든 범위 변경 `PROPOSED — NOT APPROVED`. 기존 `ROADMAP.md`의 8단계 순서를 기준으로 하고, 선행 관계와 Go/No-Go만 구체화한다.

---

## 1. 분류 기준

- **Must**: 핵심 루프 4개 중 하나라도 빠지면 알파 판정 불가.
- **Should**: 있으면 검증이 명확해지지만 빠져도 알파 판정은 가능.
- **Could**: 시간이 남을 때만.
- **Not in Alpha**: 설계 자리만 두고 구현하지 않음.

### 2.3 Could

- 생존자 NPC 대화(최소 텍스트 1종)
- 이동 오브젝트 장애물 판정
- 부품 연결 그래프 2단계 이상
- 기체 외형 커스터마이징 최소 세트(외형만, 전투 영향 없음)

## 4. 마일스톤과 Go/No-Go

| 단계 | 기간(가설) | 산출물 | Go/No-Go 조건 |
|---|---|---|---|
| M0 기획 확정 | 1주 | 본 검토 문서 승인, 변경 제안 승인/기각 | 사용자 승인 (제작 승인과 별도) |
| M1 공통 기반 | 2주 | 데이터 저장, 세션 잠금, 종료 처리, 텔레포트 | 저장/복구 테스트 통과(T-D시리즈) |
| M2 기체 이동 | 2주 | 저거노트 이동, P-MOVE, 네트워크 측정 | **Go/No-Go 1**: 8인 기준 서버→클라 ≤ 25KB/s, 조작 반응 지연 체감 기준 통과 |
| M3 무장·피해 | 3주 | 무장 4종, 장갑·부위 판정, 파괴 효과 | **Go/No-Go 2**: 판정 로그 일치율 100%(서버 재계산), 투사체 200 동시 프레임 기준 |
| M4 갈고리·대시·에너지 | 2주 | 갈고리 판정, 대시, 에너지 규칙 | **Go/No-Go 3**: 모바일 실기기 입력 시나리오 통과(V-U1) |
| M5 Legion·AI | 3주 | 3병종, 지휘관, 3계층 AI, 웨이브 1종 | **Go/No-Go 4**: AI 틱 ≤ 12ms(근거리 40 기준) |
| M6 월드·임무 | 3주 | 검증 지역, 거점, 임무 4종, 스캐빈징 | 핵심 루프 1회 완주 30분 내 가능 |
| M7 성장·보급·UX | 2주 | 레벨, 업그레이드, 수리 비용, 정비·창고 UI, 오디오 | 첫 세션 목표(05 §6) 내부 플레이 3회 충족 |
| M8 통합·알파 판정 | 2주 | 부하, 모바일, 저장, 네트워크 테스트 | **알파 통과 기준**(08 §4.1) |

- 총 19주 가설(인력 구성 미상). 병행 가능 구간을 반영하면 14~16주 수준으로 줄 수 있으나, 인력 규모를 사용자가 알려주면 재산정한다.
- 각 Go/No-Go 실패 시: (a) 범위 축소, (b) 설계 변경 제안, (c) 기간 연장 중 **사용자가 선택**한다(Claude가 임의로 결정하지 않음).

## 5. 개발 순서의 근거

- 기존 로드맵(공통 기반 → 전투 → AI → 월드 → 성장 → UX → 테스트)을 유지하되, **이동 프로토타입(M2)을 가장 먼저 검증**한다.
- 이유: 조작감과 네트워크 비용은 다른 모든 시스템의 전제이며, 여기서 실패하면 설계 전체를 바꿔야 한다. 기존 로드맵은 "전투 시스템"으로 묶여 있어 이 위험이 늦게 드러날 수 있다.

## 6. 알파 검증 목표 (기능 수보다 우선)

1. 조작 반응: 모바일 실기기에서 갈고리·대시·무장 조작이 "의도대로 됐다"는 응답률 ≥ 90%(플레이테스트 설문, 가설).
2. 전투 판독: 피격 후 손상 부위를 3초 내 정확히 지목하는 비율 ≥ 80%.
3. 선택 긴장: 출격 1회당 "무엇을 아낄지" 선택이 발생한 횟수 ≥ 3(로그 기준).
4. 안정: 8인 연속 60분 세션에서 데이터 손실 0, 서버 크래시 0.
5. 첫 세션 30분 내 레벨 2 이상 도달 비율 ≥ 80%.

## 7. 범위 통제 규칙

- 새 기능 제안은 **Must를 건드리지 않는 경우에만** 알파에 추가 가능.
- 기능 추가 시 반드시 같은 양의 Should/Could를 제외한다.
- "있으면 좋겠다"는 요청은 DEFER 목록에만 기록한다.
