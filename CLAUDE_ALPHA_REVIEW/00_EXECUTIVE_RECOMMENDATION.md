## 1. 한 문장 요약

기존 기획의 **재미 축(1인칭 콕핏, 갈고리 기동, 대시·에너지 긴장감, 부위별 손상과 현장 수리, 서버별 월드 전쟁 사이클)은 대부분 유지**하되, **구현 비용이 가장 큰 부분 세 가지(물리 기반 갈고리 줄, 부위 수 과다, 파티원 임시 탑승)를 단순화하거나 이후로 미루고**, 권한 구조를 "서버 권위 판정 + 클라이언트 조작 반응"으로 명확히 나누는 것을 권장합니다.

## 2. 알파 핵심 루프 (재확인)

메인 메뉴 → 오픈월드 검증 지역 입장 → M1A4 출격(탑승) → 이동·갈고리·대시·무장 전투 → 보급 차량/임무/탐험으로 물자 확보 → 본부·정비 → 업그레이드·수리 후 재출격.

알파 성공은 "콘텐츠가 많은가"가 아니라 **아래 4가지가 측정 가능하게 재미있고 안정적인가**로 판정합니다.

1. 조작 반응성: 데스크톱·모바일에서 이동·조준·갈고리 입력 후 체감 지연이 목표치 이내인가 (`08` 참조).
2. 전투 판독성: 피해 부위와 Legion 상태가 HUD만으로 읽히는가.
3. 선택의 무게: 손상·에너지·탄약·수리 비용 중 하나를 고르는 순간이 매 출격마다 생기는가.
4. 운영 안정성: 8인 서버에서 서버 권위 판정이 깨지지 않고, 종료·재접속 시 계정 데이터 손실이 0인가.

## 4. 알파 범위 요약 (세부는 `07`)

- 플레이어 동시 접속: **알파 서버 최대 8명**(초기 가설), 부하 테스트는 16명까지 (`08`).
- Feldress: **M1A4 저거노트 1종 + 데이터 검증용 경량형 1종** (경량형은 게임 내 제공이 아니라 프레임워크 검증용 내부 프로토타입) (NEW).
- 무장(KEEP): 기존 결정대로 M1A4 초기 후보 주무장 2종·보조무장 2종을 유지하고 그중 1+1을 장착. 추가 주무장 1종(일반 화폐 구매)을 Should로 포함. 탄약 종류 2종, 갈고리 1종, 대시 1종.
- 월드: 검증 지역 1곳 (약 2×2 km 가설), 본부 1곳, 안전 거점 1곳(생존자), 전방 거점 2곳, 복구 시설 4종.
- 임무: 반복 임무 템플릿 4종 + 거점 방어 웨이브 1종.
- 성장: 계정 레벨 상한 10(가설), 화폐 2종(일반·재료 1종), XP 분리.
- 제외(DEFER): PvE, PvP, 스토리 캠페인, 설계도/가챠 구조, 공중 대시 세부 차별화, 파티원 임시 탑승, 월드 전체 영속화, 프리미엄 화폐 상품, 원작 캐릭터 NPC 상호작용.

## 5. 기존 기획 중 유지 / 축소 / 변경 / 보류 요약

- **유지(KEEP)**: 1인칭 콕핏 기본, 3인칭 토글, 우클릭 자유 회전, 갈고리 조준점 방식·홀드 입력·독립 좌우, 대시 쿨다운 공유, 에너지 규칙 2026-11-20 결정 전체, 점프 차징, 파일럿 별도 체력과 본부 부활 후 기체 직접 선택, 필드 수리의 중단·재시작 규칙, 파괴 기체 고비용 기지 수리, 무장 변경 장소 제한, 장갑 우선 피해 규칙, 유료 가챠 지양, 서버별 월드 독립.
- **축소·구체화(CHANGE)**: 갈고리 줄 물리, 부품 수, 장애물 대상(이동 오브젝트 제외), 알파 저장 범위, 파티원 임시 탑승, 서버 최대 인원(8명 가설), 공중 대시 별도 상수 세트.
- **보류(DEFER)**: 파티원 임시 탑승, PvE·PvP 등 모든 후속 모드, 공중 대시 세부 차이, 두 갈고리 무입력 세부 물리, 기체별 갈고리 줄 외형.
- **제거(REMOVE)**: 알파 범위 내 없음. 기존 문서의 "잔해 회수" 일반 제안은 이미 현재 규칙이 아니므로 제외 상태 유지.

자세한 항목별 근거와 승인 단위는 `09_DECISION_CHANGE_REGISTER.md`를 기준으로 하세요.
