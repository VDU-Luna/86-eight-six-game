# 03. Legion 및 AI 시스템

- 작성일: 2026-11-20 · 버전 v0.1 · 기준 `main` / `9d2d42b`
- 상태: 모든 제안 `PROPOSED — NOT APPROVED`. 수치는 초기 가설.

---

## 1. 목표

- Legion은 플레이어의 **움직임과 선택을 강제하는 위협**이어야 한다. 많은 수가 아니라 **읽을 수 있는 행동**이 중요하다.
- 기존 결정 유지: 지속 출현 + 조건부 대규모 웨이브, 지역별 기본 출현, 지휘관 영향, 지휘권 승계 규칙(새 지휘관 자동 생성 금지), 3단계 손상(정상·손상·파괴), 원거리 추상화.

## 2. 알파 병종 (CHANGE: 수량 축소)

원작 병종명과 특징은 원작 자료 대조가 필요하므로 **역할명**으로만 표기한다. 원작 명칭 매핑은 `10` 검증 항목.

| 코드 | 역할 | 행동 특징 | 손상 단계 | 알파 |
|---|---|---|---|---|
| L-A 근접 돌격형 | 근거리 압박 | 빠른 접근, 짧은 공격 주기, 저 HP | 3단계 | 포함 |
| L-B 중사격형 | 거리 유지 사격 | 엄폐 추구, 느린 재조준, 중 HP | 3단계 | 포함 |
| L-C 장갑 중량형 | 전선 유지 | 느림, 대형 장갑, 기동부 손상 시 이동 감소 | 3단계 | 포함 |
| L-D 지휘관급 | 지휘 효과 제공 | 반경 내 아군 행동 보정, 제거 시 해제 | 간소화 3단계 | 포함(1종) |
| L-E 특수형 | 특수 작전용 | — | — | DEFER |

- 기존 "원거리 Legion은 추상 전황" 규칙은 **원거리 AI 계층(§4)**에 적용.
- 최종 임무 보스는 알파 범위 외(DEFER).

## 3. 상태 머신 (개체 단위, 근거리 계층 기준)

상태: `대기(Idle)` → `경계(Alert)` → `추적(Chase)` → `교전(Engage)` → `재배치(Reposition)` / `후퇴(Retreat)` → `사망(Dead)`.

| 전이 | 조건 | 비고 |
|---|---|---|
| 대기 → 경계 | 플레이어 감지 반경 진입 또는 소음(발사·대시) | 감지 반경 기체 크기 기준 가변 |
| 경계 → 추적 | 시야선 확보 후 2초 유지 | 시야 판정은 레이 1회 |
| 추적 → 교전 | 사거리 진입 | 병종별 사거리 |
| 교전 → 재배치 | 피해 누적 또는 엄폐 필요 | L-B 전용 |
| 어떤 상태 → 후퇴 | 기능 부품 파괴 2개 이상 또는 지휘관 제거 혼란 | 짧은 재집결 |
| 임의 → 사망 | 기체 파괴 | 정리 후 풀 반환 |

- 상태 전이는 **서버 틱 기반**, 상태 변화만 클라이언트에 복제.
- 모든 Legion이 독립 복잡 AI를 가지지 않는다(PART G 원칙): 근거리만 FSM, 중거리는 단순 상태 2~3개, 원거리는 전황 수치.

## 4. AI 3계층 (NEW, 기존 원칙의 수치화)

| 계층 | 거리(플레이어 기준, 가설) | 갱신 주기 | 상한(동시) | 처리 |
|---|---|---|---|---|
| 근거리 | ≤ 150 studs | 10Hz | 40 | 전체 FSM, 개별 이동·공격 |
| 중거리 | 150~400 studs | 2Hz | 80 | 단순 상태(추적·공격·대기)만 |
| 원거리 | > 400 studs | 0.2Hz 전황 갱신 | 무제한(수치) | 개체 생성 없이 **추상 집단값**(수, 위치 구역, 지휘 상태) |

- 원거리 집단이 근거리로 진입하면 **구역 기준으로 개체를 스폰**하고 상태를 재구성한다(재활성화 상태 동기화). 상태 손실 허용 범위는 "행동 방향과 대략 수"까지.
- 계층 전환 히스테리시스: 진입 기준 150, 이탈 기준 170 studs(잦은 전환 방지).

### 성능 저하 사다리 (제안)
| 단계 | 트리거(서버 틱 평균) | 조치 |
|---|---|---|
| 0 정상 | ≤ 12ms(AI 예산) | 기본 |
| 1 경고 | 12~16ms | 중거리 주기 2Hz→1Hz |
| 2 축소 | 16~20ms | 근거리 상한 40→30, 신규 스폰 간격 2배 |
| 3 보호 | > 20ms | 신규 스폰 중단, 원거리 집단 확률 갱신만 |
- 단계 복귀는 3초 연속 정상일 때만(진동 방지).

## 5. 감지·추적·공격 규칙

- 감지: 시야선(레이 1), 소음 이벤트(발사·대시·폭발), 지휘관 공유 감지. 시야 밖 인지는 최대 4초 유지.
- 추적: 목표 플레이어 우선순위 = 가장 가까운 Feldress → 최근 공격자 → 임무 목표. 기체 탑승자와 파일럿 모두 대상.
- 공격: 병종별 발사 주기, 명중 판정은 **투사체 규칙 재사용**(02 §5).
- 파일럿 보호 정책: Legion은 파일럿 상태 대상도 공격. 알파에서 기체 외부 파일럿의 별도 AI 우선순위 가중치는 DEFER.
- 플레이어 주변 스폰 금지(§6), 시야 내 스폰 금지.

## 6. 스폰·웨이브

### 지속 출현 (상시)
- 구역별 기본 출현 목록(병종 가중치)과 **구역 인구 상한**.
- 플레이어 근처 120 studs 이내와 시야 내 스폰 금지.
- 스폰 간격 최소 2초(서버 전역).

### 조건부 웨이브 (KEEP 혼합 구조)
- 발동 조건 = 시간 경과 AND/OR 플레이어 활동량 AND/OR 임무 진행. 알파는 **"거점 방어 웨이브" 1종**만.
- 웨이브 규모 적응: 접속 인원 1명당 +15% 가설, 상한 2배(【검증 필요】).
- 웨이브 종료 조건: 목표 수 처치 또는 거점 방어 성공 시간 도달. 실패: 거점 점령 상실.
- 웨이브 실행 중 임무 중복은 **웨이브가 우선**, 임무 진행은 일시 정지(01 임무 설계 `04` 참조).

## 7. 지휘관급 (L-D)

- 배치: 일반 구역 낮은 확률(가설 5%), 웨이브 확정 등장 1회(KEEP).
- 효과: 반경 60 studs 내 아군 공격 주기 -10%, 상호 감지 공유(KEEP 취지).
- 제거: 효과 해제, 일반 Legion은 기본 행동 유지, 일부만 짧은 혼란 2초(KEEP).
- 승계: 조건을 만족하는 다른 지휘관이 **이미 존재할 때만** 지휘권 이전. 자동 생성 금지(KEEP).
- 알파 웨이브 외 상시 배치 지휘관은 1구역 1개까지(가설).

---

## 8. 손상과 자동 회복 (KEEP)

- 3단계: 정상 → 손상(성능 저하) → 파괴(기능 상실).
- 교전 중 자동 회복 없음(KEEP). 교전 이탈 후 **60초 뒤 손상 1단계 회복**(가설). 파괴는 회복하지 않음(가설: 전투 종료 후 제거와 함께 소멸).

---

## 9. 정리·풀링 (구현)

- Legion 모델은 **템플릿 클론 + 풀 재사용**. 사망 후 2초 연출 뒤 풀 반환.
- 생성 수 상한을 풀 크기로 고정해 GC 압력을 줄인다.
- 원거리 집단은 인스턴스 없음.

---

## 10. 병렬 처리 검토

- Roblox의 Parallel Luau(Actor 기반)는 연산 분산에 쓸 수 있으나, 게임 상태 변경은 메인 스레드 제약이 있다【검증 필요: 알파 프로토타입에서 이득 측정 전까지 기본 설계에 넣지 않음】.
- 제안: 알파는 **단일 스레드 AI 관리자**로 구현하고, 프로파일링 후 `경로·시야 레이` 같은 순수 연산만 병렬화 후보로 둔다.

## 11. 테스트 기준 (상세는 `08`)

- AI 틱 예산 12ms 이내(근거리 40, 중거리 80, 투사체 200 동시).
- 지휘관 제거 후 혼란·승계 로직 시나리오 테스트.
- 원거리→근거리 전환 시 상태 튐 비율 측정.
