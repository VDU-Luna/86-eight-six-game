# UI & Audio

상태: 알파 기본 원칙 일부 확정, 세부 레이아웃 미정

## 이미 정해진 기본 원칙
- 메인 메뉴: 3D 정비고 배경, 고정 카메라, 왼쪽 모드 카드
- 알파에서 오픈월드만 이용 가능하며 나머지 모드는 개발 중 표시
- 정비소와 창고는 팝업이 아닌 별도 전체 화면
- 전투 HUD는 최소 정보 중심
- 1인칭 HUD에는 Feldress 실루엣과 부위별 손상 색상을 표시
- 3인칭 시점에는 별도 부위 피해 HUD를 표시하지 않음
- 피격 시 짧은 시각 피드백, 파괴된 부위는 HUD 실루엣에서 잠시 점멸

## 알파에서 남은 설계
- 주/보조 무장별 탄창·예비 탄약·재장전 표시
- 에너지 및 상태 정보의 구체적 배치
- 임무 목표, 지도, 시설 상호작용, 보급 UI
- 정비소/창고의 세부 레이아웃과 정보량
- PC·모바일·컨트롤러 입력 배치 및 접근성 옵션
- 사운드 세부 사양과 오디오 믹스

## 오디오 범위
- Feldress 이동·점프·갈고리·대시
- 무기 발사·재장전·피격 피드백
- 레기온 행동과 전투
- 시설·UI 상호작용
- 배경 음악 및 전투 음악

원작 음악·음성·효과음 등 권리 보호 콘텐츠를 무단 복제하지 않고 독자 제작 또는 적법하게 허가된 자산을 사용합니다.
