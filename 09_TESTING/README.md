# Testing

상태: 알파 설계 및 구현 단계에서 단계별 검증 필요

테스트는 모든 기획이 끝난 뒤 한 번에 수행하지 않습니다. 이동·전투·AI·저장 등 위험도가 높은 기반 시스템은 프로토타입/구현 단계에서 작은 단위로 먼저 검증하고, 알파 통합 단계에서 전체 흐름을 검증합니다.

## 우선 검증 범위
- Feldress 이동·점프·갈고리·대시의 반응성과 충돌
- 주/보조 무장 동시 발사·독립 재장전·탄약 공유
- 명중·피해·부위 손상과 HUD 연동
- 레기온 AI 수와 갱신 주기에 따른 서버 부하
- 여러 플레이어의 전투·파티·월드 상태 동기화
- 계정 데이터 및 서버별 월드 데이터 저장·복구
- 서버 재접속 및 비정상 종료 후 상태 처리
- PC·모바일 입력과 화면 대응
- 메모리·프레임·네트워크 부하 및 오류 기록

## 알파 통합 검증
- 메인 메뉴에서 오픈월드 진입
- 임무·탐험·기지·보급·정비·성장 핵심 루프
- 서버별 독립 월드 상태와 계정 데이터 분리
- 신규/복귀 플레이어의 기본 진행 경험
- 최적화 및 알파 공개 기준 충족 여부
